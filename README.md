# Крошка — кофейня

Адаптивный сайт кофейни для портфолио: меню, подбор напитка по вкусу, светлая и тёмная тема, русский, английский и узбекский языки.

## Возможности

- Меню с категориями и описаниями напитков.
- Рекомендация бариста с расчётом стоимости выбранного молока.
- Сохранение вкусовых предпочтений, языка и темы в браузере.
- Адаптивная компоновка и изображения для разных экранов.
- Управление с клавиатуры и поддержка reduced motion.

## Запуск локально

Нужен Python 3. Из корня репозитория:

```sh
python3 -m http.server 8000 --directory site
```

Откройте http://localhost:8000. Сборка и установка npm-пакетов не требуются.

## Публикация

Сайт находится в `site/`. GitHub Actions публикует его в GitHub Pages после изменений в ветке `main`. В Settings → Pages должен быть выбран источник GitHub Actions.

## Состав

- `site/index.html` — разметка.
- `site/*.css` — оформление и адаптивность.
- `site/script.js` — меню.
- `site/coffee.js` — подбор напитков и диалоги.
- `site/preferences.js` — переводы, язык и тема.
- `site/assets/` — фотографии.

Это портфолио-концепт. Онлайн-заказы, оплата и реальные контакты кофейни не подключены. Шрифты загружаются из Google Fonts; при недоступности используются системные замены. Настройки хранятся только в localStorage, серверной базы нет.
